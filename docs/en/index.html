Neon Pointer

A macOS menu bar app that draws a translucent neon shape around your mouse cursor, so you can always spot it at a glance.

Download (Releases) GitHub Repository

Features

4 shapes

Choose from circle, ring, cross, or square as the cursor decoration.

Fine-grained customization

Freely adjust color, size, opacity, glow intensity, and line width.

Menu bar control

Runs as a menu bar app — toggle it on/off and change every setting from there.

Settings auto-save

Settings are persisted automatically using UserDefaults.

Never gets in your way

The overlay is click-through, so it never interferes with the app underneath.

No Accessibility permission needed

Cursor position is read only via NSEvent.mouseLocation, so no permission prompt is required.

Requirements

  • macOS 14 or later
  • Xcode 15 or later (used for command-line builds)
  • XcodeGen: brew install xcodegen

Build

If you'd rather not use the prebuilt dmg from Releases, you can build it from source instead.

git clone https://github.com/Tanishi-z/NeonPointer.git
cd NeonPointer

make build   # produces dist/NeonPointer.app
make run     # build and launch
make dmg     # produces dist/NeonPointer.dmg
make clean   # remove build artifacts

NeonPointer.xcodeproj is generated automatically from project.yml via xcodegen. Don't edit it directly — change project.yml instead.

Install

  1. Download NeonPointer.dmg from Releases and open it
  2. Drag NeonPointer.app into Applications
  3. The first time only, right-click → Open the app and confirm "Open"

Since the app is unsigned, double-clicking it will show a "developer cannot be verified" warning. If it still won't open, run: 

xattr -cr /Applications/NeonPointer.app
