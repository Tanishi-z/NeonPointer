Neon Pointer

マウスカーソルの周りにネオン風の半透明シェイプを表示して、 カーソル位置を一目で見つけられるようにする macOS 常駐アプリです。

ダウンロード (Releases) GitHub リポジトリ

特徴

4種類の形状

円・リング・十字・四角からカーソルの装飾形状を選択できます。

細かなカスタマイズ

色・サイズ・不透明度・グロー（発光の強さ）・線幅を自由に調整できます。

メニューバーから操作

常駐アプリとしてメニューバーに常駐し、ON/OFFと全設定をそこから操作できます。

設定は自動保存

UserDefaults を使って設定を自動的に保存します。

操作を邪魔しない

オーバーレイはクリックを透過するため、下のアプリの操作を妨げません。

アクセシビリティ権限不要

NSEvent.mouseLocation のみでカーソル座標を取得するため、権限の許可は不要です。

必要環境

  • macOS 14 以上
  • Xcode 15 以上（コマンドラインビルドに使用）
  • XcodeGen: brew install xcodegen

ビルド方法

Releases の dmg を使わず、自分でソースからビルドしたい場合は以下の手順です。

git clone https://github.com/Tanishi-z/NeonPointer.git
cd NeonPointer

make build   # dist/NeonPointer.app を生成
make run     # ビルドして起動
make dmg     # dist/NeonPointer.dmg を生成
make clean   # 生成物を削除

NeonPointer.xcodeproj は project.yml から xcodegen によって自動生成されます。直接編集せず project.yml を変更してください。

インストール

  1. Releases から NeonPointer.dmg をダウンロードして開く
  2. NeonPointer.app を Applications にドラッグ
  3. 初回のみ、アプリを 右クリック → 開く を選んで「開く」を押す

未署名アプリのため、ダブルクリックだと「開発元を検証できません」と表示されます。 それでも開けない場合は次を実行してください。 

xattr -cr /Applications/NeonPointer.app
